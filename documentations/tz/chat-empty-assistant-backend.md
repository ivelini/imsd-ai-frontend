# ТЗ: витрина публичного чата не должна отдавать пустые реплики ассистента

- **Статус:** выполнено 2026-11-13 (бэкенд; витрина фильтрует пустой `content` в SQL до лимита
  `PAGE`, тест `PublicChatMessagesTest::test_get_skips_empty_assistant_steps`)
- **Дата:** 2026-11-13
- **Адресат:** бэкенд `imsd-backend` (Laravel)
- **Потребитель:** фронт `aalyans.ru` (Next.js) — виджет `src/features/chat/`
- **Связанные:** `../backend/documentations/api-maps/public-chat.md`,
  `public-chat-frontend.md`; фронт-документ `documentations/integrations/chat.md`

## 1. Проблема

На шагах вызова инструментов агент сохраняет реплику `assistant` с пустым `content`:
`AbstractAgentLoop::addAssistantMessage` пишет `$response->text`, а на тул-колле текст пустой.
`PublicChatMessagesReader` отдаёт все реплики ролей `user`/`assistant` и не фильтрует пустые
(`domains/AI/Services/Chat/PublicChatMessagesReader.php`).

Следствия на фронте:

1. В ленте появляется пустой пузырь ассистента.
2. Поллинг считает диалог отвеченным, как только последняя реплика — `assistant`, и
   останавливается. Настоящий ответ приходит следующей репликой через 1–2 с и до
   перезагрузки страницы не показывается.

Доказательство (dev, 13.11.2026, диалог по вопросу «какие зимние шины подойдут на 205/55 R16»):

```
id 70469 user      "Подскажите, какие зимние шины подойдут на 205/55 R16?"
id 70470 assistant ""                    ← пустая реплика, шаг инструментов
id 70471 assistant "Зимние шины 205/55 R16 в наличии (цены ...)"
```

## 2. Что нужно от бэка

Витрина публичного диалога отдаёт только реплики с непустым `content`:

- `PublicChatMessagesReader::after()` — исключить `assistant` с пустым `content`
  (например, `where('content', '!=', '')` либо фильтр после выборки с сохранением
  семантики лимита `PAGE = 200`);
- шаги инструментов в публичной витрине — служебные, как `system`: наружу не идут.

Допустимая альтернатива — не создавать пустую `assistant`-реплику в `addAssistantMessage`,
если `$response->text === ''` и есть вызовы инструментов; тогда исправление в агентском цикле.

## 3. Критерии приёмки

- `GET /api/chat/messages` не содержит реплик `assistant` с пустым `content` на любом
  сценарии с инструментами.
- После пустой реплики (если она останется в протоколе админки) витрина возвращает только
  непустой ответ; поллинг фронта дожидается его без перезагрузки.
- Покрыто тестом бэка: диалог с шагом инструмента — в ответе нет пустого `assistant`.

## 4. Фронт

Фронт не меняется: он рассчитывает на контракт «`content` — текст реплики», пустые реплики
не фильтрует по решению пользователя от 13.11.2026. До выполнения ТЗ виджет временно
показывает пустой пузырь и может не дождаться ответа до перезагрузки.
