# 0010. Блок статьи — общий объект фронта: страница выводит HTML, если в корне пришёл article

- **Статус:** Accepted
- **Дата:** 2026-11-07
- **Связанные ADR:** 0008 (бейдж — общий объект фронта), 0001 (баррел `shared/api/data.ts`)

## Контекст
Бэк ввёл привязку статей к маркировкам (`article_markings`, ADR бэка `marking/0058`):
статья становится контентом зоны витрины — каталога, подбора по авто, модели, карточки.
Где показывать статью, решает бэк: он либо кладёт объект в ответ, либо нет. Фронту нужен
один способ выводить такой контент во всех зонах, не смешивая его с данными товара.

## Решение
- Объект `article: { body: string }` в корне ответа, рядом с `data`/`meta` — как `badges`
  (ADR 0008), а не поле внутри товара или листинга.
- `body` — HTML RichEditor; фронт рендерит как есть (`dangerouslySetInnerHTML`), как тело
  статьи на `/articles/{slug}`.
- Условие одно: объект есть — блок есть; поля нет или `null` — блока нет.
- Ядро в `shared/`: тип `ArticleBlockDto`/`ArticleBlockData`, чистый адаптер `toArticleBlock`,
  компонент `ArticleBlock` (`.article-content.article-block`); страница решает, куда его
  поставить.
- Зоны: каталоги шин и дисков (конец `.catalog-section`, после пагинации), подбор шин
  и дисков (уровень результата), модель шин (внизу `.model-description`), карточки шин
  и дисков (секция перед «Наличие»).
- Заголовка у блока нет: бэк отдаёт только HTML.

## Почему (альтернативы)
Отдельное поле в DTO товара/листинга отклонено: статья — свойство зоны или маршрута,
а не товара, и смешалась бы с данными карточки. Повторять разметку в каждой зоне
отклонено: как с баджами, разметка разъедется (правило двух). Заголовок и обёртка с `h2`
отклонены: пользователь выбрал «только HTML», заголовок — часть HTML статьи. Полный объект
статьи как в `/api/articles/{slug}` отклонён для первой итерации: фронту нужен только
`body`. Новый CSS-блок отклонён: переиспользованы стили `.article-content` (включая
правило картинок RichEditor от 06.11.2026). Рендер готовой разметки на бэке отклонён:
бэк отдаёт данные, разметку собирает фронт.

## Последствия
Зоны подключают общий компонент без дублирования; бэк включает контент по маркировкам,
не меняя фронт. Пока бэк поле не отдаёт, в dev работает мок `src/data/articleBlock.ts`
(только `NODE_ENV=development`) — тесты и прод идут по настоящему контракту; снятие:
удалить файл и заменить вызовы в шести API-функциях. Страница модели дисков — отдельный
план (нет API, макета и свободного URL). Если понадобится заголовок или несколько статей
на зону, контракт расширяется полями `title` / `articles[]`.
