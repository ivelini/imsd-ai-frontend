## Правило для моков

**При создании новых моков (`src/data/*`) — структура ответа должна соответствовать API бэка:**
- `{ "data": ... }` — обёртка для одиночного объекта
- `{ "data": [...], "meta": { "current_page", "last_page", "per_page", "total" } }` — коллекция
- `{ "data": [...], "facets": { ... }, "meta": { ... } }` — каталог с фасетами
- Имена полей: `per_page` (не `perPage`), `current_page` (не `page`)
- Цены — целые числа, без копеек
- Enum-значения — латинские строки (value, не label)
- **Facets включают `label`** — бэк отдаёт готовые строки для отображения, фронт не строит словари (контракт `api-contract.md`)

Формат ответа текущих моков (`src/shared/api/data.ts`) должен быть переведён
на эту структуру при рефакторинге мок-слоя перед подключением реального API.
