# Чат: передача выбранного города сайта

> Source: локальные документы проекта — .claude/plans/chat-city.md, documentations/integrations/chat.md (раздел «Город витрины»)
> Collected: 2026-11-13
> Published: 2026-11-13

## Контракт бэка (обновлён 2026-11-13)

POST /api/chat принимает `{"message": "...", "city": "cheljabinsk"}` (или `city_id`; приоритет
у `city_id`). `city` — слаг города сайта; неизвестный слаг — город магазина по умолчанию
(не 422), несуществующий `city_id` — 422. Город сохраняется в диалоге и определяет цены,
наличие и сроки доставки в ответе; без города — `shop.default_city`.

Код бэка: `PostPublicChatController` резолвит слаг через `CityReader::resolveId`;
`StartPublicChatTurn::rememberCity` обновляет `session.city_id`, если город отличается, —
то есть город применяется на каждом POST, а не только при создании диалога.

Пустые реплики `assistant` (шаги инструментов) бэк с 13.11.2026 в витрину не отдаёт —
ТЗ `tz/chat-empty-assistant-backend.md` выполнено (`PublicChatMessagesReader` фильтрует пустой
content в SQL до лимита PAGE; тест `PublicChatMessagesTest::test_get_skips_empty_assistant_steps`).

## Решение фронта

- Идентификатор — слаг `city`, не `city_id`: сайт живёт на слагах URL (ADR 0004;
  api-contract: value совпадает с сегментом).
- Город отправляется с каждым POST (бэк обновляет город сессии).
- Значение — город, который посетитель видит на сайте: выбранный `useUIStore.cityValue`
  (синхронизирован с `?city=` через CityHydrator) либо дефолт geo (`useGeo.defaultCityValue`).
  Логика вынесена в чистую функцию `effectiveCitySlug(cityValue, defaultSlug?)`
  (`src/shared/lib/cityUrl.ts`), `useCity` отдаёт `citySlug`.
- Пока geo не загружена и выбора нет — город пуст, ключ `city` в тело не попадает, бэк берёт
  город магазина (штатный фолбэк контракта).
- Смена города при открытом диалоге не сбрасывает его (решение пользователя 13.11.2026):
  история и остаток лимита сохраняются, следующий ответ считается по новому городу.
- `sendChatMessage` переведён на один объект аргументов `{message, token?, city?}`:
  позиционные `(message, token?, city?)` давали неудобный порядок.
- `ChatWindow` берёт `useCity().citySlug` и передаёт в `useSendChatMessage().mutate`.
