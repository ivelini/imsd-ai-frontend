# Префиксные размеры w/p в URL каталога + 404 на мусор (реализация 21.08.2026)

> Source: обновление ADR 0002 (documentations/adr/0002-catalog-url-config.md) и реализация 21.08.2026
> Collected: 2026-08-21
> Published: 2026-08-21

## Проблема

Позиционная пара чисел в сегментах (`/catalog/tires/185/60/r15`) не выражала профиль без ширины: первое число всегда становилось `width`. Фильтр UI (независимые селекты) штатно позволяет выбрать профиль без ширины — URL терял значение при round-trip (`{profile: 60}` → сегмент `60` → `{width: 60}`).

## Решение

Именованные префиксные сегменты размеров, каноничный порядок `season/brand/w/p/r`:

- `w185` → `width=185` (парсер `/^w(\d+)$/i`)
- `p60` → `profile=60` (парсер `/^p(\d+)$/i`)
- `r15`/`r13c` — как было (диаметр, C-размеры строкой)

Любая комбинация выразима: `/p60/r15` (без ширины), `/w185/r15` (без профиля), `/r15`.

## Строгость грамматики: 404 на мусор

Сегмент, не распознанный ни одним парсером (голое число, дубль бренда/сезона, сезон после бренда/размеров, строка вне каноничного порядка), — `InvalidCatalogUrlError`, страница отдаёт 404 (`notFound()` в page + generateMetadata через `parseCatalogParamsOr404`). Раньше нераспознанное «съедалось впустую» и молча портило фильтр (голое число могло стать `brand="185"`). Семантика сезон/бренд стала строгой: сезон — только первый сегмент и без бренда; бренд — первая строка без размерных префиксов и чисел.

## Контракт справочника

`GET /api/reference/filter/tire` отдаёт value с префиксами (`w185`, `p60`, `r15`) — 1:1 с сегментами URL (контракт api-contract: value == сегменты). Адаптер `toFilterOptions` (`sizeOpts`) нормализует голое число в префикс (`185` → `w185`) — переходный период до обновления бэка. UI-селекты ширины/профиля кодируют value как у диаметра: `value="w${width}"`, парсинг `wnum`/`pnum` (по аналогии с `diam`).

## Что не менялось

- `toTireListQuery` — листинг-query шлёт числа (`width[]=185`), бэк принимает числа.
- WHEELS_CONFIG — у дисков ширина осталась числом (`6.5`); строгий parseUrl применяется и к ним: нераспознанный сегмент — тоже 404.
- Обратная совместимость со старыми URL (голые числа в пути) сознательно не нужна — проект в разработке.
