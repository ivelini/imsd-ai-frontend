# Порт макета страницы ошибки в error.tsx (живая обвязка)

> Source: План .claude/plans/error-page-mockup-port.md и прогоны на прод-сборке (фронт aalyans.ru)
> Collected: 2026-10-16
> Published: 2026-10-16

Макет `.template/error.html` (28-я страница: карточка «Сервис временно недоступен»
с шапкой/подвалом) подставлен в фоллбэк ошибок — карточка рисуется внутри живой обвязки.

## Решение (выбор пользователя из двух вариантов)

- `src/app/error.tsx` (новый, граница сегмента, client component) — карточка макета
  1-в-1 (`.error-section → .error-card`: `error.svg`, `h1` «Сервис временно недоступен»,
  два абзаца) + кнопка «Обновить» (`window.location.reload()`); `console.error(error)`
  (digest — для логов).
- Почему не статичная копия макета в `global-error`: живая обвязка не дублирует
  разметку (меню, телефоны, корзина, вход — настоящие компоненты; моки/localStorage
  работают). Цена варианта: город в шапке пустой (остров `CityBadge` сходит в API и не
  получает ответа; при клиентской навигации может остаться из кэша) и один запрос
  уходит впустую. Копия захардкодила бы город/телефон/счётчик корзины и дрейфовала бы
  при правках реальной шапки.
- `global-error.tsx` остаётся нижним слоем — на случай падения самой обвязки (его
  дизайн не менялся).
- Стили `.error-section/.error-card/.error-picture/.error-title/.error-text/.error-button`
  перенесены из `.template/assets/css/style.css` в конец `src/app/style.css`
  (метка 16.10.2026, правило ui-porting 9); ассет — `public/assets/img/error.svg`
  (в мокапе остаётся).
- Прогон поправил ожидание: 500-ответ и у `error.tsx` — оболочка `__next_error__`;
  карточку и обвязку рисует клиент (без JS пусто — у дефолтной страницы Next то же).

## Прогоны (заглушка 500, прод-сборка)

- Красный: текущий фоллбэк — самостоятельная страница («Что-то пошло не так», шапки нет).
- Зелёный, 5 сценариев: прямой заход — карточка макета в живой обвязке (шапка/подвал;
  город пустой); «Обновить» после оживления бэка → 12 карточек и город вернулся;
  клиентский переход — карточка, обвязка жива (логотип ведёт на главную); мок-страницы
  без живых фетчей живы; мок-страница с живым гео → карточка.
- Проверки: `npm test` 80 passed, `tsc --noEmit` чисто, `eslint` 0 ошибок
  (15 прежних предупреждений).
