# Правила работы с Git

> Source: .claude/rules/git.md (проектный файл)
> Collected: 2026-08-19
> Published: Unknown

- **Коммиты — только по явному указанию пользователя.** Не коммитить автоматически после завершения задачи или исправления.
- В сообщении коммита указывать модель AI-агента: `model: <имя-модели>` в теле коммита.
