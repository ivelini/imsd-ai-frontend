# Перенос мокапа шиномонтажа (booking) в .template проекта (12.09.2026)

> Source: план `.claude/plans/booking-domain-port.md` + реализация 12.09.2026 (код в рабочем дереве, без коммита)
> Collected: 2026-09-12
> Published: 2026-09-12

Исходник — соседний проект `~/my/imsd-ai/tireslot/.template` (11 страниц записи на шиномонтаж).
Перенесён в домен `.template/booking/` проекта aalyans.ru: содержимое страниц — 1-в-1,
каркас (шапка, футер, крошки, полоса акций, попап города, оверлей каталога) — проектный.

## Что выяснилось про исходник

- `tireslot/.template/assets/css/style.css` = база проекта (первые 4701 строка, побайтово
  совпадают с `.template/assets/css/style.css`) + блок booking-стилей начиная с 4702 строки.
  То есть дизайн-фундамент у проектов общий, переносились только 1383 строки хвоста.
- Конфликтов имён классов с базой нет: `.alert`, `.status-badge`, `.step*`, `.calendar*`,
  `.time-chip`, `.code-*`, `.booking-*` в базе проекта отсутствуют.
- Иконок не хватало четырёх: `calendar.svg`, `clock.svg`, `phone.svg`, `warning.svg`.
  Остальные (logo, login, busket, note, order_check, order_check_a, town, message, close,
  соцсети) в проекте есть.

## Состав перенесённых страниц (11)

Поток записи (корень `.template/booking/`):

1. `index.html` — шаг 1: дата (календарь на месяц) и время (чипы слотов)
2. `services.html` — шаг 2: готовые комплексы, услуги с ценами за колесо, параметры авто
3. `details.html` — шаг 3: контактные данные (имя, телефон, госномер), согласие
4. `code.html` — шаг 4: код из SMS (4 разряда), таймер повторной отправки
5. `success.html` — запись подтверждена: номер записи, состав, сумма, телефон мастерской
6. `code-expired.html` — состояние: код устарел (новый код на тот же номер)
7. `unavailable.html` — состояние: выбранный слот закрыли, запись не создана

«Мои записи» (`.template/booking/my/`):

8. `index.html` — вход по телефону без регистрации
9. `code.html` — код из SMS как вход
10. `list.html` — список записей со статусами (подтверждена/завершена), отмена
11. `cancelled.html` — запись отменена, время освобождено

## Правила продукта, закодированные в макете

- Цена в прайсе — **за 1 колесо**; количество пересчитывается; итог зависит от радиуса и типа
  автомобиля (легковая / кроссовер / внедорожник).
- Запись не позднее чем **за 1 час** до начала и **в пределах 30 дней**.
- **Слот не удерживается** до подтверждения: запись создаётся только после ввода кода из SMS.
- Код из SMS действует **15 минут**; повторная отправка — по таймеру.
- **Отмена бесплатна**, пока до начала больше 2 часов; ближе — только по телефону мастерской.
- Код из SMS служит и входом в «Мои записи» (без регистрации), пока запись активна.

## Решения порта

- Размещение: `.template/booking/` (поток) + `.template/booking/my/` («Мои записи»).
- **Шапка — 1-в-1 как на остальных страницах проекта**, без новых пунктов. Вход в «Мои записи» —
  ссылками: один пункт в футере (группа сервисных ссылок), крошки, кнопка на экране успеха.
  Это единственное расхождение каркаса с проектом.
- Страница «Контакты» исходника **не переносилась** — в проекте уже есть `/service-page/kontakty`.
- Стили: блок booking дописан в `.template/assets/css/style.css` (+1206 строк) с датой;
  вырезаны 25 правил адаптации чужого каркаса (`body.ts-body`, `.ts-header-row`, `.contacts-*`,
  `.header-my-booking`, `.header-tagline`, `.footer-address`, `.footer-hours`); все `font-weight: 800`
  заменены на 700 (в базе проекта веса 800 нет).
- `src/app/style.css` в этой фазе не менялся — стили домена переедут вместе с React-портом.
- React-роутов `/booking/*` пока нет; домен живёт только как макет-эталон.
