# Пагинация типоразмеров модели: диаметр в URL + «Показать ещё» (ADR 0003)

> Sources: ADR 0003, 2026-08-12
> Raw: [ADR 0003](../../raw/project/2026-08-19-adr-0003-model-sizes-pagination.md)

## Overview

Страница модели `/tires/[modelSlug]` рендерила все типоразмеры разом (до 842 карточек у viatti). Гибридное решение: вкладки по диаметрам (диаметр в URL `?diameter=r17`) + «Показать ещё» по 24 карточки внутри секции.

## Решение

- Вкладки-диаметры — первичная навигация; выбранный диаметр в URL (та же идея, что фильтры каталога, ADR 0002); кнопки + `router.replace` без полного навигационного цикла.
- «Показать ещё» по 24 карточки — клиентское состояние, сброс при смене диаметра. SSR первого экрана совпадает с гидрацией (24 карточки + кнопка).

## Почему

- `?page=N` — теряется группировка по диаметрам, переделка вёрстки `ModelSizes`.
- Только «Показать ещё» — 28 кликов на 842 карточки, URL не фиксирует позицию.
- Только вкладки — внутри больших диаметров (135 шт.) всё ещё простыня.

## Последствия

DOM ограничен (24 + кнопка), URL модели переиспользуем. «Показать ещё» — не SEO-фактор: поисковик видит первые 24 (осознанный компромисс). При подключении API батч (24) и механика могут переехать на бэк-контракт (items + has_more). Глубокие ссылки `#diameter-rXX` заменены на query — формат изменился.
