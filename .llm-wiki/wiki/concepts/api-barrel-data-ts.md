# Баррел `shared/api/data.ts` как точка подключения API (ADR 0001)

> Sources: ADR 0001, 2026-08-07
> Raw: [ADR 0001](../../raw/project/2026-08-19-adr-0001-barrel-api-data.md)

## Overview

`shared/api/data.ts` — God Object на 700 строк (функции 8 доменов, 32 потребителя). Решение: разделить на доменные модули `shared/api/<домен>.ts`, а `data.ts` оставить баррелом (`export *`), чтобы контракт импортов не менялся. Подключение API = замена моков на fetch внутри модулей.

## Решение

Доменные модули: base, nav, geo, home, service-pages, catalog, product, cart, checkout, auth, articles, seo. Потребители не знают о модулях — импортируют баррел как раньше.

## Почему

- Прямые доменные импорты у 32 потребителей — «честнее», но 32 файла правок разом при той же единой точке замены внутри модулей.
- Оставить God Object — гарантированный конфликтный PR при подключении API.
- Цена: прослойка барреля между потребителями и доменами.

## Последствия

Контракт импортов заморожен на мок-фазу; `export *` расширил публичную поверхность (delay — безвредно). Пересмотрим при подключении API: баррел можно убрать постепенно, если потребителям понадобятся разные модули.
