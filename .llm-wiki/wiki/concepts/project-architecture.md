## Overview

Проект — интернет-магазин шин и дисков aalyans.ru: Next.js 16 приложение (`src/`), переносимое 1-в-1 из статичного HTML-мокапа (`.template/`). Данные — моки `src/data/`, имитирующие ответы Laravel-бэка (`backend/`, соседний проект); подключение API — поэтапное через rewrites. С 21.08.2026 каталог шин полностью живой (листинг, гео, SEO-мета). С 30.09.2026 запись на шиномонтаж (`booking`) работает как React-поток на живом API (пять роутов `/booking/*`), раздел «Мои записи» остаётся макетом. С 20.10.2026 подбор шин и дисков по автомобилю — живой API (справочники Vehicle + результат с размерами/спецификациями и товарами). С 22.10.2026 карточки товара шин и дисков — тоже живой API, товарные моки удалены. С 05.11.2026 статьи, меню шапки/футера и системные страницы — живой API, моки статей и сервисных страниц удалены. С 11.11.2026 модель дисков и адреса карточек дисков с модельным сегментом (`/wheels/{бренд}/{модель}/{слаг}`, ADR 0011); блок статьи — строка HTML из текстов маршрутов админки, dev-мок снят. С 13.11.2026 на всех страницах — виджет публичного чата с ИИ-ассистентом: анонимная сессия, город сайта уходит слагом с каждым POST, ответ ассистента приходит поллингом; с 16.11.2026 у последней реплики показываются кликабельные варианты ответа (`options`); дефект бэка с пустыми `assistant`-репликами исправлен 13.11.2026. С 24.11.2026 корзина и оформление заказа — на живом API: корзина гостя по `X-Device-Id`, двухшаговое оформление с SMS-кодом, черновик и снимок заказа в `sessionStorage`. С 24.11.2026 личный кабинет — тоже живой API: регистрация по SMS-коду, вход/выход, восстановление пароля по SMS и ссылке, профиль и уведомления; сессия — Sanctum Bearer-токен, вход по телефону сливает гостевую корзину с корзиной аккаунта.

## Слои

- **`src/app/`** — роутинг и композиция страниц; **`src/features/`** — домены (каталог, корзина, товар, автоподбор, чат); **`src/shared/`** — ядро (api-баррел, UI, lib, layout); **`src/data/`** — моки; **`src/stores/`** — Zustand (только UI).
- **`.template/`** — эталон вёрстки: 28 страниц, BEM-классы, без JS. `style.css` — база 4701 строка плюс доменные блоки в конце с пометкой даты (booking — +1206 строк, 12.09.2026; стили самого потока записи с 30.09.2026 живут в `src/app/style.css`, в макете остались только стили «Моих записей»).

## Ключевые роуты

- Каталог шин `/catalog/tires/[[...params]]` — сегменты `season/brand/wN/pN/rN` (префиксные размеры: `w185`, `p60`, C-размеры `r13c`; невалидный сегмент → 404) + query (`price_min`, `price_max`, `delivery[]`, `studded`, `page`).
- Автоподбор `/catalog/{tires|wheels}/auto/[[...auto]]` — живой каскад марка→модель→год→модификация; сегменты — слаги (`acura/integra/1999/1-8i`; числовой id — legacy-редирект); справочники `/api/reference/vehicle/makes/{make}/models/…` (`category=tire|wheel`), результаты `/api/catalog/tires|wheels/by-vehicle/{make}/{model}/{year}/{mod}`.
- Модель шины `/tires/[brandSlug]/[modelSlug]` — живая (16.10.2026: `GET /api/catalog/tire-models/{brand}/{model}`, короткий слаг модели; размеры — листинг с фильтром `model`); карточка шины `/tires/[brandSlug]/[modelSlug]/[sizeSlug]` — живая с 22.10.2026 (`GET /api/catalog/tires/{brand}/{model}/{size}`, `{size}` — полный слаг позиции). Диски с 11.11.2026 — зеркало шин: модель `/wheels/[brandSlug]/[modelSlug]` (`GET /api/catalog/wheel-models/{brand}/{model}`), карточка `/wheels/[brandSlug]/[modelSlug]/[sizeSlug]` (`GET /api/catalog/wheels/{brand}/{size}`, слаг без префикса бренда). Тексты витрины — `GET /api/reference/store`. Адреса mirror API (ADR 0007; диски — ADR 0011).
- Сервисные: `/cart` и `/checkout` → `/checkout/code` — живой API (24.11.2026: корзина гостя по `X-Device-Id`, оформление с SMS-кодом), `/order/[id]` — снимок заказа из `sessionStorage`, `/order-status` — статичная подсказка. Аккаунт (24.11.2026): `/auth/login`, `/auth/register` (код из SMS на той же странице), `/auth/restore-password` → `/auth/new-password?phone=…`, `/reset-password?token&email`; `/account` → редирект на живой `/account/profile` (ФИО/e-mail, телефон, уведомления), остальные `/account/*` — заглушки. Детали — [account-auth-live-api](account-auth-live-api.md). Блог и системные страницы — живой API (05.11.2026): `/articles` (фильтр категорий и пагинация в URL), `/articles/[id]`, `/service-page/[slug]`; меню шапки/футера — `GET /api/reference/article-menu`, пункты ведут на `/service-page/{slug}`. Детали — [articles-live-api](articles-live-api.md).
- Шиномонтаж (booking): `/booking` → `/booking/services` → `/booking/details` → `/booking/code` → `/booking/success` — поток на живом API; состояния отказа — состояния шага 4. Вход — пункт «Шиномонтаж» в шапке. «Мои записи» (`my/*`) — макет без API. Детали — [booking-domain](booking-domain.md).
- Чат — не роут: виджет в `src/app/layout.tsx` на всех страницах (панель запуска в правом нижнем углу, окно с анонимным диалогом). Детали — [chat-live-api](chat-live-api.md).

## Данные и состояние

- Моки в `src/data/` (nav, products — HOME_DATA главной, бенефиты корзины и текст согласия оформления); доступ только через `shared/api/data.ts`. Моков товаров, статей, сервисных страниц, корзины, заказов и аккаунта нет.
- Источник истины по маршрутам API — `../backend/documentations/scramble/public-api.json` (Scramble-экспорт, генерится в docker `scramble:export-docs`), не моки; товарные эндпоинты и `/reference/store` в экспорте на 22.10.2026 ещё не появились.
- **Живое (30.09.2026):** запись на шиномонтаж — слоты `GET /api/booking/slots`, каталог услуг `GET /api/booking/catalog`, код `POST /api/booking/code`, подтверждение `POST /api/booking/confirm`, справочник `GET /api/reference/booking` (адрес, телефон, сроки); слой — `shared/api/booking.ts`, ошибки различаются машинными кодами `booking.*`.
- **Живое (21.08.2026):** каталог шин целиком — листинг `GET /api/catalog/tires` (адаптеры `toTireListQuery`/`toTireProduct`, город слагом `city=` — резолвит бэк), гео `GET /api/reference/city` (`toGeoData`; мок `data/geo.ts` удалён), опции фильтра `GET /api/reference/filter/tire`. SEO-мета страницы — `meta.seo {title, description}` → generateMetadata/h2. Карточка показывает из листинга также ПВЗ (`origin.pick_up`), наличие (`count_in_stock`) и зачёркнутую цену (`old_price`) — 16.10.2026. С 16.10.2026 живой и каталог дисков: листинг `GET /api/catalog/wheels` и фильтр `GET /api/reference/filter/wheel` (адаптеры `toWheel*`, decimal-значения нормализует бэк). С 16.10.2026 живая и страница модели шин: `GET /api/catalog/tire-models/{brand}/{model}` + размеры листингом (`model=&brand=&diameter[]=`); фото товаров — `images[0].url` (`/storage/…`; раздача требует `storage:link` на бэке, колонка карточки — 172px). С 20.10.2026 живой и подбор шин и дисков по автомобилю: справочники `GET /api/reference/vehicle/makes/{make}/models/{model}/…` (`category=tire|wheel`) и результаты `GET /api/catalog/tires|wheels/by-vehicle/{make}/{model}/{year}/{mod}` (секции OEM/альтернатива, пары front/rear, лимит 12; у дисков — допуски width/ET/hub); адресация — слагами, numeric `id` — legacy-редирект; моки `AUTO_*` и SEO-мок удалены. С 22.10.2026 живы карточки товара: `GET /api/catalog/tires/{brand}/{model}/{size}` и `GET /api/catalog/wheels/{brand}/{size}` (`shared/api/product.ts`, 404 → null), тексты витрины — `GET /api/reference/store`; удалены `data/catalog.ts`, `PRODUCT_STATIC`, `ALL_PRODUCTS`. С 05.11.2026 живы статьи и меню: `GET /api/reference/article-menu`, `GET /api/reference/article-categories`, `GET /api/articles`, `GET /api/articles/{slug}` (`shared/api/articles.ts`, `shared/api/nav.ts`); моки `data/articles.ts` и `data/servicePages.ts` удалены. С 11.11.2026 жива модель дисков (`GET /api/catalog/wheel-models/{brand}/{model}`), адреса карточек дисков — трёхсегментные (`/wheels/{бренд}/{модель}/{слаг}`). С 13.11.2026 жив публичный чат: `POST /api/chat` (город сайта слагом `city` с каждым сообщением), `GET /api/chat/messages` (`shared/api/chat.ts`, с 16.11.2026 — `options` у реплики), токен в localStorage `chat_session_token`, поллинг полным списком; виджет — `features/chat/` в layout. С 24.11.2026 живы корзина и оформление: `GET/POST/PATCH/DELETE /api/cart*` (корзина гостя по `X-Device-Id`, город слагом в запросе), `GET /api/reference/checkout`, `GET /api/reference/delivery-points`, `POST /api/checkout/code`, `POST /api/checkout` (`shared/api/cart.ts`, `shared/api/checkout.ts`; `Idempotency-Key` на обоих шагах, черновик `checkout-draft` и снимок `checkout-order-snapshot` в `sessionStorage`). С 24.11.2026 живой и аккаунт: `POST /api/auth/register/code`, `/api/auth/register`, `/api/auth/login`, `/api/auth/logout`, `/api/auth/password/forgot|reset/{sms,email}`, `GET|PATCH /api/account/profile`, `POST /api/account/profile/phone/code`, `PATCH /api/account/profile/phone`, `GET|PUT /api/account/notification-settings` (`shared/api/auth.ts`, `shared/api/account.ts`); с Bearer корзина и checkout работают с корзиной аккаунта (`OptionalSanctumAuth`), вход/регистрация сливают гостевую корзину по `X-Device-Id`. Остальное — моки (главная, стартовая `/catalog`). Кэш — на бэке (`tire-list:v5`, результаты подбора — `tire-by-vehicle:v1`/`wheel-by-vehicle:v1`, карточки — `tire-product:v1`/`wheel-product:v1`).
- Zustand — только UI (город, попапы, меню); корзина — React Query + серверная корзина (гостя по `X-Device-Id` в localStorage `device-id`; с Bearer — аккаунта), сессия — Sanctum Bearer-токен (`auth-token` в localStorage; без «Запомнить меня» — в sessionStorage).
- **Фоллбэк ошибок бэка (16.10.2026):** любое необработанное исключение (5xx, недоступность) → HTTP 500 и карточка «Сервис временно недоступен» из макета (`error.html`, 28-я страница) внутри живой обвязки — граница `src/app/error.tsx`; `global-error.tsx` — нижний слой (падение самой обвязки). Цена живой обвязки — пустой город в шапке при мёртвом бэке; детали — [backend-error-fallback](backend-error-fallback.md).
- Кастомный CSS (страницы без макетов) — в конце `src/app/style.css` с датой.

## Разработка

- Dev-сервер через Docker (`make up`, порт 30034), образ с `USER node` uid 1000; build/`npm run dev` не запускать одновременно с контейнером (общий `.next`, кэш turbopack).
- Верификация мокапа: `node .claude/verify/verify.mjs` (скриншоты 5×28), `check-all.mjs` (переполнения, битые картинки, битые ссылки). Требуют `playwright` — в `devDependencies` проекта его нет.
- Формат slug: бренды — транслит (`bmw`, `michelin`, `nokian-tyres`), модели — как в данных; слаг позиции шины — `brand-model-width-profile-rNN-index[-studded][-runflat]` (`yokohama-bluearth-e70b-215-55-r17-94v`), диска — `brand-name-specs` (`ls-disk-ls-367-…`).
