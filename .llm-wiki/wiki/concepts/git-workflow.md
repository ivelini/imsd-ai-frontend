# Правила работы с Git

> Sources: .claude/rules/git.md, 2026-08-19
> Raw: [git.md](../../raw/project/2026-08-19-rule-git.md)

## Overview

Коммиты — только по явному указанию пользователя; в сообщении коммита указывается модель AI-агента.

## Правила

- Не коммитить автоматически после завершения задачи или исправления — только по явному указанию.
- Формат сообщения: `model: <имя-модели>` в теле коммита.
