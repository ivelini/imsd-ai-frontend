# Конфиг-грамматика URL каталога (ADR 0002)

> Sources: ADR 0002, 2026-08-07
> Raw: [ADR 0002](../../raw/project/2026-08-19-adr-0002-catalog-url-config.md)

## Overview

URL-грамматика каталога (сегменты + query) описывается конфигом `CatalogUrlConfig` + обобщёнными `parseUrl`/`buildUrl` в `shared/lib/parseParams.ts`. Шины и диски — данные (`TIRES_CONFIG`/`WHEELS_CONFIG`), а не копии каркаса.

## Решение

Конфиг: `segmentParsers`, `queryParsers`, `segmentOrder`, `extraQueryFields`. Старые функции остались обёртками — потребители не менялись. Новая категория (мотошины) = новый конфиг без копирования каркаса.

Семантики: сезон — только первый нечисловой сегмент, бренд — первый не-сезонный; «поздний» season в URL игнорируется.

## Почему

Rule of Three допускал оставить две пары функций — обобщили на второй копии (каркас идентичен ~70%, третья категория почти наверняка появится). Цена: уровень абстракции при двух реализациях; порядок query-параметров в URL может отличаться (на парсинг не влияет).

## Последствия

Семантики зафиксированы в одном месте, поведение воспроизведено 1-в-1. `parseParams.ts` — кандидат на unit-тесты (Vitest подключён). Пересмотрим при отсутствии третьей категории (конфиг — оверинжиниринг; обёртки сохраняют совместимость).
