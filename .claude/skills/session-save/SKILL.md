# Сохранение итогов сессии

Запускается пользователем в конце рабочей сессии (после завершения задачи/фазы). Цель — следующая сессия (или навык) продолжила работу без потери контекста.

## 1. Обновить план (`.claude/plans/`)

1. Найти **активный план** — самый свежий по дате/правкам файл в `.claude/plans/` (если несколько — уточнить у пользователя).
2. Добавить/обновить секцию «Факт выполнения»:
   - **✅ Сделано** — список выполненных пунктов за сессию (что, где, ключевые решения)
   - **⚠️ Требует доработки** — что осталось (включая известные ограничения)
   - **Инциденты сессии** — что ломалось и как починено (hydration, CORS, баги парсинга) — это экономит часы в будущем
3. Если план завершён — пометить заголовок «✅ ВЫПОЛНЕНО <дата>».
4. План не удалять без явного указания пользователя.

## 2. Обновить документацию (`docs/`)

1. Проверить, затронуты ли за сессию архитектурные решения, описанные в `docs/architecture/`:
   - `data-flow-mock-api-layer.md` — движение данных, подключение API
   - `api-contract.md` — формат данных фильтра, контракт с бэком
2. Если решения изменились — обновить файл и **синхронизировать копию в Obsidian Vault**:
   `Obsidian Vault/projects/template/architecture/<файл>.md` (та же структура).
3. Новые архитектурные правила — зафиксировать в `.claude/rules/`.

## 3. Сохранить память

Обновить файлы в `/home/perminoviv/.claude/projects/-home-perminoviv-my-imsd-ai-template/memory/`:

1. **Основной файл статуса** (`template-to-frontend-port.md` или профильный, напр. `catalog-phase-2-context.md`):
   - Что сделано за сессию (кратко, со ссылками на файлы/коммиты)
   - Что осталось / следующий шаг
   - Ключевые решения и инциденты
2. **`MEMORY.md`** — обновить hook-строку, если описание изменилось.
3. Правила запоминания:
   - Не дублировать то, что уже записано в коде/планах (только неочевидное)
   - Относительные даты конвертировать в абсолютные
   - Коммиты — только по явному указанию (`.claude/rules/git.md`), в план/память это не входит

## 4. Итог

Сообщить пользователю кратко:
- План: что обновлено (сделано/осталось/инциденты)
- Документация: что обновлено, синхронизировано ли в vault
- Память: какие файлы обновлены, следующий шаг
