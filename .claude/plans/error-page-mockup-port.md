# Порт макета error.html в фоллбэк ошибки

Статус: итерация 2 — выбран вариант 1 (живая обвязка, 16.10); тест-лист на подтверждении.

## Цель

Страница макета `.template/error.html` (28-я: шапка/подвал 1-в-1 как на главной,
карточка «Сервис временно недоступен» с картинкой `error.svg`, без кнопок, без JS)
должна стать страницей фоллбэка. Сейчас фоллбэк — самостоятельный `global-error.tsx`
(без обвязки, коммит 4d39de9, не выложен).

## Решение (вариант 1 — живая обвязка, выбран 16.10)

`src/app/error.tsx` рисует карточку макета внутри настоящих шапки/подвала. Живое всё,
что можно: телефоны и меню — моки (`getNav`), корзина/вход — localStorage; город —
нет: запрос острова уйдёт и не получит ответа, город в шапке пустой (при клиентской
навигации может остаться из кэша React Query). `global-error.tsx` остаётся нижним
слоем — на случай падения самой обвязки. Прогон поправил ожидание: 500-ответ и у
`error.tsx` — оболочка `__next_error__`, карточку и обвязку рисует клиент (без JS
пусто; у дефолтной страницы Next то же самое).

Отклонено — статичная копия макета в `global-error.tsx`: буквально ноль запросов, но
город/телефон/счётчик корзины захардкожены (неверные данные для других городов и
пользователей), ссылки — заглушки, копия шапки дрейфует при правках реальной.

## Задачи (проект для варианта 1)

1. `src/app/error.tsx` (новый) — client component: карточка макета 1-в-1
   (`.error-section` → `.error-card`: `error.svg`, `h1` «Сервис временно недоступен»,
   два абзаца), кнопка «Обновить» → `window.location.reload()`, `console.error(error)`.
   Рисуется внутри root layout — шапка/подвал/меню не дублируются, живут как обычно.
2. `public/assets/img/error.svg` — перенос ассета из `.template/assets/img/`
   (в мокапе файл остаётся).
3. `src/app/style.css` — перенос блока `.error-section/.error-card/.error-picture/
   .error-title/.error-text` + media ≤639px из `.template/assets/css/style.css`
   в конец с пометкой даты (правило ui-porting 9: стили переезжают вместе с портом).
4. `global-error.tsx`, стили `.error-page*` — не трогаем (нижний слой).
5. Прогон по тест-листу; визуальная сверка карточки с макетом (скриншоты).

Кнопки: в макете их нет; в карточку добавляется «Обновить» (перезагрузка); «На
главную» не нужна — в живой шапке логотип и меню.

## Прогоны

- **Красный** (прод-сборка :3010, заглушка 500; до `error.tsx`): `/catalog/tires` →
  500, текущий фоллбэк — самостоятельная страница (title «Что-то пошло не так — Альянс»),
  шапки/подвала/карточки макета нет.
- **Зелёный** (та же сборка после правки):
  - сценарий 1: 500; в браузере карточка «Сервис временно недоступен» (картинка,
    «Обновить») внутри живой обвязки — шапка и подвал на месте; город в шапке пустой —
    единственная потеря; запросы к /api — только город от острова шапки (запрос + ретрай),
    оба падают;

    ошибки исчезла, город появился («Челябинск» — на скриншоте);
  - сценарий 3: с живой главной клик по каталогу → карточка, шапка/меню живы; клик по
    логотипу → главная;
  - сценарий 4: `/`, `/articles`, `/cart` → 200;
  - сценарий 5: мок-страница с живым гео (`/tires/viatti-strada-2/185-55-r15-84h`) →
    карточка; title страницы остаётся из её метаданных (метаданные-моки отработали).
- **Проверки**: `npm test` 80 passed; `tsc --noEmit` чисто; `eslint` 0 ошибок
