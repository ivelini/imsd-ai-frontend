# Страницы входа и регистрации

## Цель
Добавить в мокап две самодостаточные страницы авторизации в стиле шаблона:
`user/login.html` (вход) и `user/register.html` (регистрация).

## Контекст
- Референс aalyans.ru: ссылка «Войти» в шапке ведёт на `/login`; сама форма рендерится JS-ом и недоступна для парсинга — делаем по конвенциям шаблона.
- В шапке уже есть блок `.login header-icon-and-btn` с иконкой `login.svg` и текстом «Войти» — страницы входа пока нет.
- Образец вёрстки: `order/index.html` (каркас, формы, футер), стили форм — `--color-*` токены, инпуты 36px с радиусом 5px, красные кнопки 260×40 (`.order_form_method_btn_submit`).

## Задачи
1. `user/login.html` — каркас как у order/index.html (каталог-меню, гео-окно, шапка, бейджи, хлебные крошки «Главная / Вход», футер) + форма входа: телефон/e-mail, пароль, «Забыли пароль?», чекбокс «Запомнить меня», кнопка «Войти», ссылка на регистрацию.
2. `user/register.html` — та же обвязка + форма регистрации: имя, телефон/e-mail, пароль ×2, согласие с политикой, кнопка «Зарегистрироваться», ссылка на вход.
3. CSS-блок `/* ===== Вход / регистрация ===== */` в `assets/css/style.css` после секции «Корзина / заказ» + медиа-запросы ≤639px.
4. Добавить обе страницы в `.claude/verify/verify.mjs` и `.claude/verify/check-all.mjs`.
5. Прогнать `node .claude/verify/check-all.mjs` (без скриншотов) — 0 issues.

## Ожидаемый результат
Две статичные страницы без JS в стиле шаблона, ссылки-плейсхолдеры `href="#"`, проверка переполнений на 5 разрешениях проходит.
