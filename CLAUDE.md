# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Статичный HTML-мокап дизайна пользовательского сайта интернет-магазина шин и дисков (проект IMS-DI, aalyans.ru). Исходники дизайна — Figma-файл и реальный сайт aalyans.ru (разрешённые запросы к ним — в `.claude/settings.local.json`).

Реальный продукт живёт в соседних директориях проекта `imsd-ai`: `frontend/` (Next.js 15), `admin/` (React SPA), `backend/` (Laravel) — у каждой свой CLAUDE.md. Эта папка — эталон вёрстки, по которому переносится UI в `frontend/`.

## Команды

Сборки, линта и тестов нет — это чистые статические HTML. Просмотр: открыть любой `.html` в браузере или поднять статику из этой директории (`python3 -m http.server`). Интернет нужен: jQuery 3.6.4 и Slick 1.8.1 подключаются с CDN; fancybox — локально в `assets/fancybox/`.

## Разрешения

Макет верстается под **5 контрольных разрешений**, сгруппированных по брейкпоинтам в `style.css`:

| Разрешение | Брейкпоинт (CSS) | Диапазон | Устройства |
|---|---|---|---|
| 390px | `max-width: 639px` (+ узкий каталог `≤648px`) | 0–639 | Смартфоны |
| 768px | `640–1023px` | 640–1023 | Планшеты / телефоны-горизонталь |
| 1024px | `1024–1365px` | 1024–1365 | Ноутбуки малые |
| 1366px | `≥1366px` | 1366+ | Десктоп (базовый) |
| 1920px | (тот же `≥1366`) | — | Широкие мониторы |

Канонические точки: **640 / 1024 / 1366** (токены `--bp-*` в CSS), мобильный брейкпоинт каталога — 648.

Верификация Playwright: 390/768/1024/1366/1920 × 12 страниц = 60 комбинаций (`node .claude/verify/verify.mjs`), проверка переполнений и битых картинок без скриншотов — `node .claude/verify/check-all.mjs`.

## Архитектура

- **12 самодостаточных страниц, сгруппированных по доменам**: `index.html` (главная), `catalog/` (index + 4 состояния фильтра), `product/`, `cart/`, `order/`, `popups/` (гео-окно, каталог-меню, корзина). Каждая — полный документ **без JavaScript** (удалён при рефакторинге; все состояния — статичные HTML).
- **Единый стиль**: весь CSS в `assets/css/style.css` (~3,6 тыс. строк); дизайн-токены через CSS-переменные `--color-*`, `--gap-*`, `--bp-*`; именование классов BEM-подобное (`header-location-block-main`, `geo-location-window-list-item`).
- **Страницы не ссылаются друг на друга** — все ссылки это плейсхолдеры `href="#"`; «навигация» — просто открыть файл.
- **Интерактив → страницы-состояния**: слайдеры на scroll-snap, фильтр цены — статичная имитация, попапы — отдельные страницы в `popups/`.
- **Попапы и модалки инлайнятся прямо в страницы**; `popups/` — репозиторий таких фрагментов для копирования.
- Изображения: SVG инлайн в разметке + статичные файлы в `assets/img/` (51 шт.).

## Заметки

- `lang="en"` на всех страницах при русском контенте — артефакт мокапа, менять не нужно.
- Изменения вёрстки здесь обычно служат источником для переноса в `frontend/` (Next.js) — сверяться со стилями мокапа при работе там.
