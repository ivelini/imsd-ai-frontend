# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Статичный HTML-мокап дизайна пользовательского сайта интернет-магазина шин и дисков (проект IMS-DI, aalyans.ru). Исходники дизайна — Figma-файл и реальный сайт aalyans.ru (разрешённые запросы к ним — в `.claude/settings.local.json`).

Реальный продукт живёт в соседних директориях проекта `imsd-ai`: `frontend/` (Next.js 15), `admin/` (React SPA), `backend/` (Laravel) — у каждой свой CLAUDE.md. Эта папка — эталон вёрстки, по которому переносится UI в `frontend/`.

## Команды

Сборки, линта и тестов нет — это чистые статические HTML. Просмотр: открыть любой `.html` в браузере или поднять статику из этой директории (`python3 -m http.server`). Интернет нужен: jQuery 3.6.4 и Slick 1.8.1 подключаются с CDN; fancybox — локально в `assets/fancybox/`.

## Архитектура

- **7 самодостаточных страниц**: `main.html`, `catalog.html`, `product.html`, `cart.html`, `order.html`, `def.html`, `popup.html`. Каждая — полный документ со своим инлайн-JS в конце; `assets/js/` пуст.
- **Единый стиль**: весь CSS в `assets/css/style.css` (~3,6 тыс. строк); именование классов BEM-подобное (`header-location-block-main`, `geo-location-window-list-item`).
- **Страницы не ссылаются друг на друга** — все ссылки это плейсхолдеры `href="#"`; «навигация» — просто открыть файл.
- **`cart.html`, `order.html`, `def.html`, `popup.html` имеют `<title>Главная</title>`** — это фрагменты/варианты главной: корзина, оформление заказа, дефолтный шаблон (шапка + гео-окно), коллекция попапов и модалок (каталог-меню, геолокация, соцсети, футер).
- **Попапы и модалки инлайнятся прямо в страницы**; `popup.html` — репозиторий таких фрагментов для копирования.
- Изображения: SVG инлайн в разметке + статичные файлы в `assets/img/` (51 шт.).

## Заметки

- `lang="en"` на всех страницах при русском контенте — артефакт мокапа, менять не нужно.
- Изменения вёрстки здесь обычно служат источником для переноса в `frontend/` (Next.js) — сверяться со стилями мокапа при работе там.
